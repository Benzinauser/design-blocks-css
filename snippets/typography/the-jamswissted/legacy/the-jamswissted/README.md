# The Jam - Swissted

A Pen created on CodePen.

Original URL: [https://codepen.io/petebarr/pen/BaymYWg](https://codepen.io/petebarr/pen/BaymYWg).

Swissted is a project by Mike Joyce where he redesigned old punk, hardcore, and indie rock show flyers into Swiss modern posters. This is an attempt to bring The Jam poster to life with animation. Original print https://www.swissted.com/products/the-jam-at-clouds-disco-1977

Built with SVG and the DOM, using GSAP 3 for animation.
