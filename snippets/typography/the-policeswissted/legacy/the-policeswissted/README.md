# The Police - Swissted

A Pen created on CodePen.

Original URL: [https://codepen.io/petebarr/pen/ZEYXrBK](https://codepen.io/petebarr/pen/ZEYXrBK).

Swissted is a project by Mike Joyce where he redesigned old punk, hardcore, and indie rock show flyers into Swiss modern posters. This is an attempt to bring The Police poster to life with animation. Original print https://www.swissted.com/products/the-police-at-cbgb-1978

Built with a mix of PixiJS canvas and the DOM, using GSAP 3 for animation.
